# Data availability

Source data for the two numerical experiments are available at https://github.com/pite3216-maker/gmvc-source-data. The repository contains simulation output tables, variable definitions, run provenance, and selected analysis and plotting scripts for independently checking the deposited results and recomputing their performance metrics.

# Code availability

The repository provides the data-analysis and plotting scripts for the deposited outputs. The complete model-training, optimization, and closed-loop simulation implementation is not distributed in this repository.
